# 08 - 配置与部署

## 配置方式

项目支持两种配置方式，适应不同运行环境。

### 方式一：config.py（本地开发）

```bash
cp config/config-example.py config/config.py
vi config/config.py
```

Python 模块格式，通过 `import config as cfg` 加载。

### 方式二：.env 文件（Docker / 生产）

```bash
cp .env.example .env
vi .env
```

环境变量格式，通过 `python-dotenv` 或 `export` 加载。

### 优先级

```
环境变量 > config.py > 代码默认值
```

## 本地部署

### 环境准备

```bash
# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 可选：安装 exiftool
brew install exiftool  # macOS
```

### 配置

```bash
cp config/config-example.py config/config.py
# 编辑 config.py，至少设置 IMAGE_DIR 和 API_URL
```

### 运行

```bash
# 1. 分析照片（需要 VLM 服务运行中）
python src/analysis/analyze_photos.py

# 2. 渲染今日照片
python src/render/render_daily_photo.py

# 3. 启动服务器
python src/server/server.py
```

## Docker 部署

### 构建与启动

```bash
cd deploy
docker-compose up -d
```

### docker-compose.yml 关键配置

```yaml
services:
  inktime-analyzer:
    volumes:
      - ../data:/app/data
      - /path/to/your/photos:/photos:ro  # 修改为实际照片路径
    environment:
      - LMSTUDIO_URL=http://host.docker.internal:1234/v1/chat/completions
      - LMSTUDIO_MODEL=qwen3-vl-32b-instruct
```

### NAS Docker 部署要点

- 照片目录以只读方式挂载（`:ro`）
- VLM 服务地址使用 `host.docker.internal`（Docker Desktop）或宿主机 IP
- 数据库和输出目录需要持久化挂载

## systemd 服务部署

### 创建服务文件

```ini
# /etc/systemd/system/inktime-server.service
[Unit]
Description=InkTime Server
After=network.target

[Service]
Type=simple
WorkingDirectory=/path/to/InkTime
ExecStart=/path/to/InkTime/venv/bin/python src/server/server.py
Restart=always
RestartSec=3
User=inktime

[Install]
WantedBy=multi-user.target
```

### 启用服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable inktime-server
sudo systemctl start inktime-server
```

## 定时任务

### 每日渲染（crontab）

```bash
# 每天凌晨 5 点渲染
0 5 * * * /path/to/InkTime/scripts/daily_render.sh
```

### daily_render.sh 说明

- 使用文件锁防止并发执行
- 检查 venv 和 config.py 是否存在
- 日志输出到 `logs/render.log`

## 安全建议

1. **DOWNLOAD_KEY**：修改默认值，防止照片被随意访问
2. **同步 ESP32**：修改 DOWNLOAD_KEY 后，同步修改固件中的 `DAILY_PHOTO_PATH_PREFIX`
3. **公网部署**：建议加 HTTPS 反代（nginx）+ 鉴权，或限制内网访问
4. **WebUI**：跑通后建议关闭（`ENABLE_REVIEW_WEBUI=False`）
5. **API_KEY**：如使用云端 VLM，妥善保管密钥
