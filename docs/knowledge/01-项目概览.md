# 01 - 项目概览

## 项目定位

InkTime 是一个 AI 驱动的墨水屏电子相框项目。它不是简单的随机播放相册，而是：

1. 用视觉大模型（VLM）理解每张照片的内容
2. 为照片打分（值得回忆度 + 美观度）并生成一句话文案
3. 每天从「历史上的今天」中选出最值得回忆的照片
4. 渲染为墨水屏可显示的格式，推送到 ESP32 硬件
5. 同时提供 Web 端浏览和沉浸式展示页面
6. 通过受保护的后台上传入口和独立 worker 持久化执行分析任务

## 核心价值

- **智能选片**：基于 AI 评分的「历史上的今天」，而非随机播放
- **低功耗**：Deep Sleep 待机 < 1mA，5000mAh 电池约半年续航
- **离线友好**：GPS 逆地理编码使用本地城市数据库
- **断点续跑**：照片分析支持中断后继续，不重复处理
- **多端体验**：墨水屏硬件 + Web 浏览 + 沉浸式展示页面

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| AI | Qwen3-VL-32B（或任何 OpenAI 兼容 VLM） | 照片内容理解与评分 |
| 后端 | Python 3.10+, Flask 3.1.2, SQLite | 分析、渲染、Web 服务 |
| 前端 | Bootstrap 5, Font Awesome, 原生 JS | 响应式 Web 界面 |
| 嵌入式 | ESP32-S3, GxEPD2, Arduino | 墨水屏驱动与低功耗管理 |
| 部署 | Docker, systemd, crontab | 容器化与定时任务 |

## 管理员认证组件

阶段 2 在 Web 服务器内新增独立认证分层，公开相册路由保持原有 URL、方法和响应契约：

- `src/server/extensions.py`：创建未绑定的 Flask-Login `LoginManager` 与 Flask-WTF `CSRFProtect`，由应用工厂绑定。
- `src/server/auth.py`：管理员身份、凭据校验、进程内连续失败限流、安全 `next` 校验和 `create-admin` 命令。
- `src/server/forms.py`：携带跨站请求伪造 token 的登录表单。
- `src/server/repositories/admin_user_repository.py`：复用请求级数据库连接的管理员参数化 SQL 与显式提交。
- `src/server/templates/admin/`、`src/server/static/css/admin.css`：不依赖外部内容分发网络的后台登录与首页。

认证新增固定依赖：Flask-Login==0.6.3 负责会话身份，Flask-WTF==1.3.0 负责表单和跨站请求伪造保护。

## 依赖项

### Python 依赖（requirements.txt）

- Flask==3.1.2 — Web 框架
- requests==2.32.5 — HTTP 客户端（调用 VLM API）
- Pillow==12.0.0 — 图像处理
- python-dotenv==1.0.0 — .env 文件加载
- lunar-python==1.4.8 — 农历、节气、干支、传统节日，**纯离线计算**
- zhconv==1.4.3 — 繁简转换（维基「历史上的今天」返回繁体），纯离线
- waitress==3.0.2 — 生产级 Web 服务，`python -m src.server.run_server` 为本地、systemd 和 Docker 的统一入口

### 可选 Python 依赖

- openai（可选） — 分析脚本会尝试导入，失败时自动退回 requests 调用，功能不受影响，通常不需要装

### 系统依赖（可选）

- exiftool — 更完整的 EXIF/GPS 提取
  - macOS: `brew install exiftool`
  - Linux: `sudo apt-get install -y libimage-exiftool-perl`
  - 缺失不致命，但 GPS 会不全，影响城市名与旅行加成
- sqlite3 命令行工具 — 仅用于手工查库，`sudo apt-get install -y sqlite3`。
  没装也可以用 `./venv/bin/python -c "import sqlite3; ..."` 替代
- 中文字体 — 渲染文案必需，缺失会渲染成豆腐块且不报错。
  Ubuntu 通常自带 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`，
  用 `.env` 的 `FONT_PATH` 指定；没有时 `sudo apt-get install -y fonts-noto-cjk`


### 硬件依赖

- ESP32-S3-N8R8（8MB Flash + 8MB PSRAM）
- 7.3 寸四色墨水屏 EL073TS3 或 13.3 寸六色屏
- GxEPD2 Arduino 库
