# 01 - 项目概览

## 项目定位

InkTime 是一个 AI 驱动的墨水屏电子相框项目。它不是简单的随机播放相册，而是：

1. 用视觉大模型（VLM）理解每张照片的内容
2. 为照片打分（值得回忆度 + 美观度）并生成一句话文案
3. 每天从「历史上的今天」中选出最值得回忆的照片
4. 渲染为墨水屏可显示的格式，推送到 ESP32 硬件
5. 同时提供 Web 端浏览和沉浸式展示页面

## 核心价值

- **智能选片**：基于 AI 评分的「历史上的今天」，而非随机播放
- **低功耗**：Deep Sleep 待机 < 1mA，5000mAh 电池约半年续航
- **离线友好**：GPS 逆地理编码使用本地城市数据库
- **断点续跑**：照片分析支持中断后继续，不重复处理
- **多端体验**：墨水屏硬件 + Web 浏览 + 沉浸式展示页面

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| AI | Qwen3-VL-32B（或任何 OpenAI 兼容 VLM） | 照片内容理解与评分 |
| 后端 | Python 3.10+, Flask 3.1.2, SQLite | 分析、渲染、Web 服务 |
| 前端 | Bootstrap 5, Font Awesome, 原生 JS | 响应式 Web 界面 |
| 嵌入式 | ESP32-S3, GxEPD2, Arduino | 墨水屏驱动与低功耗管理 |
| 部署 | Docker, systemd, crontab | 容器化与定时任务 |

## 依赖项

### Python 依赖（requirements.txt）

- Flask==3.1.2 — Web 框架
- requests==2.32.5 — HTTP 客户端（调用 VLM API）
- Pillow==12.0.0 — 图像处理
- python-dotenv==1.0.0 — .env 文件加载

### 系统依赖（可选）

- exiftool — 更完整的 EXIF/GPS 提取（macOS: `brew install exiftool`）

### 硬件依赖

- ESP32-S3-N8R8（8MB Flash + 8MB PSRAM）
- 7.3 寸四色墨水屏 EL073TS3 或 13.3 寸六色屏
- GxEPD2 Arduino 库
