## 快速了解项目

InkTime 是一个「拉回相册里的记忆」的墨水屏电子相框项目。核心流程：

```
照片目录 → AI 分析评分 → 数据库 → "历史上的今天"选片 → 渲染为墨水屏格式 → ESP32 下载显示
```

同时提供 Web 端照片浏览和沉浸式展示页面。
