# 06 - ESP32 硬件模块

## 概述

ESP32 模块负责从服务器下载渲染好的 .bin 文件，驱动墨水屏显示，并通过 Deep Sleep 实现超低功耗。

**固件文件**：
- `esp32/ink-display-7C-photo/ink-display-7C-photo.ino` — 7.3 寸四色版
- `esp32/ink-display-133C-photo/ink-display-133C-photo.ino` — 13.3 寸六色版

## 硬件规格

### 主控

- 芯片：ESP32-S3-N8R8
- Flash：8MB
- PSRAM：8MB（必须，用于存储 framebuffer）
- 工作频率：80MHz（降频省电）

### 屏幕（7.3 寸四色版）

| 参数 | 值 |
|------|-----|
| 型号 | EL073TS3 (GDEY073D46) |
| 分辨率 | 800×480（逻辑竖屏 480×800） |
| 颜色 | 黑/白/红/黄（4 色） |
| 接口 | SPI |
| 驱动库 | GxEPD2 (GxEPD2_730c_GDEY073D46) |
| 连接器 | 49-pin FPC |

### 引脚定义

| 引脚 | GPIO | 功能 |
|------|------|------|
| BUSY | 14 | 屏幕忙状态（输入） |
| RST | 13 | 屏幕复位（输出） |
| DC | 12 | 数据/命令选择（输出） |
| CS | 11 | SPI 片选（输出） |
| SCLK | 10 | SPI 时钟（输出） |
| DIN | 9 | SPI 数据（输出） |
| FACTORY_RESET | 38 | WiFi 重置按键（输入，低电平有效） |

### 按键功能

| 按键 | 功能 |
|------|------|
| SW1 (RESET) | 重启设备，立即拉取并显示照片 |
| SW2 (GPIO38) | 按住 SW2 再按 SW1 → 清空 NVS，重新配网 |

## 固件工作流程

```
setup() {
  1. 释放所有 GPIO hold（从 Deep Sleep 恢复）
  2. 降频到 80MHz
  3. 检查 GPIO38 是否按下 → 是则清空 NVS
  4. 从 NVS 加载配置
  5. 无有效配置 → 进入 AP 配网模式
  6. 连接 WiFi（超时 15s）→ 失败则进入 AP 配网
  7. NTP 同步时间
  8. 下载 photo_{random(0-4)}.bin
  9. 初始化墨水屏 → 显示 framebuffer
  10. 计算到下次刷新时间的分钟数
  11. 进入 Deep Sleep
}
```

## AP 配网模式

### 触发条件

- 首次启动（NVS 无配置）
- WiFi 连接失败
- 按住 GPIO38 重启

### 配网流程

1. 开启 AP 热点：`InkTime-{MAC后4位}`，密码 `12345678`
2. 启动 WebServer（端口 80）
3. 用户连接 AP，访问 `http://192.168.4.1/`
4. 配置页面提供：WiFi SSID 选择/输入、密码、服务器地址、时区、刷新时间、旋转 180°
5. 保存后自动重启

### AP 超时保护

进入 AP 模式后 5 分钟无操作 → 自动进入 Deep Sleep 到下一个刷新点，避免持续耗电。

## 低功耗设计

### Deep Sleep 配置

- 关闭 WiFi/BT
- 关闭 RTC 外设、慢速内存、快速内存
- EPD 引脚设为 INPUT_PULLDOWN 并 hold
- RTC GPIO 隔离
- 定时器唤醒（到下一个刷新时间点）

### 功耗数据

| 状态 | 电流 |
|------|------|
| Deep Sleep | < 1mA |
| WiFi 活跃 | ~80-300mA |
| 屏幕刷新 | ~50mA |

### 续航估算

5000mAh 电池，每天唤醒一次（约 30 秒活跃）：
- 日均消耗 ≈ 1mA × 24h + 200mA × 30s/3600 ≈ 25.7mAh
- 理论续航 ≈ 5000 / 25.7 ≈ 195 天（约半年）

## 下载逻辑

1. 构造 URL：`http://{backend_hostport}/static/inktime/{key}/photo_{random(0-4)}.bin`
2. HTTP GET 下载到 PSRAM framebuffer
3. 超时保护：60 秒
4. 校验大小：必须等于 480×800 = 384,000 字节
5. 失败则跳过显示，直接进入 Deep Sleep

## 墨水屏显示

1. SPI 初始化（SCLK=10, MOSI=9, CS=11）
2. GxEPD2 初始化（支持 180° 旋转）
3. 逐像素写入：framebuffer[y*480+x] → 调色板颜色
4. 调用 `display.hibernate()` 进入屏幕休眠

### PCB 模块组成

1. ESP32-S3-WROOM-1 模块
2. TP4056 锂电池充电管理
3. MIC5219 LDO 3.3V 稳压
4. 墨水屏 FPC/排针接口
5. BOOT/RESET/WiFi 重置按键
6. 滤波电容（4.7µF + 10µF + 100nF + 1µF）

## 编译与烧录

### Arduino IDE 配置

1. 安装 ESP32 Arduino Core
2. 选择开发板：ESP32-S3（开启 PSRAM：OPI PSRAM）
3. 安装库：GxEPD2
4. Flash Size：8MB
5. Partition Scheme：默认

### 烧录方式

- UART 串口烧录（推荐）：连接 H1 测试焊盘
- USB 烧录：需焊接 R2/R3/C5/C6，将 BOOT 引脚短接 GND 后上电

### 关键修改项

烧录前必须修改：
- `DAILY_PHOTO_PATH_PREFIX` — 与 `.env` 中的 `DOWNLOAD_KEY` 同步
- 引脚定义 — 如使用不同开发板
- 屏幕构造函数 — 如使用不同型号屏幕
