# 09 - 开发指南

## 本地开发环境搭建

### 前置条件

- Python 3.10+
- VLM 服务（如 LM Studio + Qwen3-VL-32B）
- 一些测试照片

### 快速开始

```bash
# 1. 克隆项目
git clone <repo-url>
cd InkTime

# 2. 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置
cp config/config-example.py config/config.py
# 编辑 config.py：设置 IMAGE_DIR 指向你的测试照片目录

# 5. 准备测试数据（少量照片即可）
mkdir -p data/photos
# 复制几张照片到 data/photos/

# 6. 启动 LM Studio，加载 qwen3-vl-32b-instruct 模型

# 7. 运行分析（建议先设 BATCH_LIMIT=3 测试）
python src/analysis/analyze_photos.py

# 8. 渲染
python src/render/render_daily_photo.py

# 9. 启动服务器
python src/server/server.py
# 访问 http://127.0.0.1:5005/
```

| 函数 | 职责 |

| 路由/函数 | 职责 |

## 调试技巧

### 分析模块调试

1. **设置 BATCH_LIMIT=1**：只处理一张照片，快速验证流程
2. **查看 VLM 输出**：脚本会打印每张照片的分析结果
3. **跳过文案生成**：注释掉 `generate_side_caption` 调用可加速测试
4. **检查数据库**：`sqlite3 data/photos.db "SELECT path, memory_score, side_caption FROM photo_scores LIMIT 5;"`

### 渲染模块调试

1. **查看预览图**：`data/output/preview_0.png` 是抖动后的效果
2. **调整阈值**：降低 MEMORY_THRESHOLD 可以让更多照片被选中
3. **指定日期测试**：修改 `TODAY = dt.date(2024, 12, 2)` 测试特定日期

### 服务器调试

1. **Flask debug 模式**：修改 `app.run(debug=True)` 开启热重载
2. **API 测试**：`curl http://127.0.0.1:5005/api/photos?page=1&limit=3`
3. **ESP32 模拟**：`curl -o test.bin http://127.0.0.1:5005/static/inktime/yourkey/photo_0.bin`

## 常见问题

### Q: VLM 返回非 JSON 格式

**原因**：模型未严格遵循 JSON 输出指令
**解决**：
- 确认使用支持视觉的模型（如 qwen3-vl）
- 检查 temperature 设置（分析用 0.2，文案用 0.7）
- 查看 `[DEBUG] 非 JSON 输出` 日志

### Q: GPS 信息缺失

**原因**：PIL 无法解析某些格式的 GPS 数据
**解决**：安装 exiftool（`brew install exiftool`），脚本会自动使用

### Q: 渲染时找不到照片

**原因**：数据库中的 path 与实际文件路径不匹配
**解决**：
- 确认 IMAGE_DIR 配置一致
- 重新运行分析（会自动清理不存在的记录）

### Q: ESP32 下载失败

**排查步骤**：
1. 确认服务器运行中：`curl http://server:5005/`
2. 确认 DOWNLOAD_KEY 匹配
3. 确认 .bin 文件存在：`ls data/output/photo_*.bin`
4. 检查 ESP32 串口日志

### Q: 墨水屏不显示

**排查步骤**：
1. 检查 SPI 接线（6 根信号线）
2. 串口是否有 "BUSY timeout" 错误
3. 确认 PSRAM 已启用（Arduino IDE 设置）
4. 确认 .bin 文件大小为 384,000 字节

## 扩展开发

### 添加新屏幕支持

1. 修改 `CANVAS_WIDTH` / `CANVAS_HEIGHT`
2. 调整 `TEXT_AREA_HEIGHT` 和字体大小
3. 修改调色板（如 6 色屏需要扩展 PALETTE）
4. 更新 ESP32 固件中的屏幕构造函数

### 修改评分逻辑

编辑 `analyze_photos.py` 中的 `system_prompt`：
- 调整分数区间定义
- 修改加分/减分规则
- 添加新的照片类型

### 修改文案风格

编辑 `generate_side_caption` 函数中的 `system_prompt`：
- 调整创作原则
- 修改禁用词列表
- 改变风格方向

### 添加新的 Web 页面

1. 在 `src/server/` 下创建模板文件
2. 在 `server.py` 中添加路由
3. 如需 API，添加对应的 API 端点
4. 前端 JS 放在 `static/js/` 目录

## 项目约定

- Python 代码使用 UTF-8 编码
- 数据库操作后立即 commit（保证断点续跑）
- 配置项优先从 config.py 读取，Docker 环境用环境变量
- ESP32 固件中的 DOWNLOAD_KEY 必须与服务端同步
- 渲染输出覆盖旧文件（不保留历史版本）
