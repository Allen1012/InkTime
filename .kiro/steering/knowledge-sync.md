# 知识库同步规则

## 项目固定路径

本项目知识库路径已由项目负责人确认为 `docs/knowledge/`。后续执行知识库生成、更新、检查、体检或同步时直接使用该目录，不再重复询问路径。

当你对项目代码进行了以下类型的修改时，必须同步更新 `docs/knowledge/` 下的对应文档。详细的文档格式和编写规范参考 `docs/knowledge/README.md`。

## 触发条件

- 新增或修改了 Flask 路由、API 端点、请求参数 → 更新 `05-Web服务器与前端.md`
- 修改了照片分析流程（VLM 调用、评分规则、Prompt、EXIF 提取逻辑）→ 更新 `03-照片分析模块.md`
- 修改了选片算法（历史上的今天逻辑、阈值、回溯策略）→ 更新 `04-图片渲染模块.md`
- 修改了渲染逻辑（画布布局、抖动算法、输出格式）→ 更新 `04-图片渲染模块.md`
- 修改了数据库表结构（新增字段、修改主键、索引变更）→ 更新 `07-数据库与存储.md`
- 修改了配置项（新增/删除/重命名配置变量）→ 更新 `08-配置与部署.md`
- 修改了 ESP32 固件逻辑（引脚定义、通信协议、低功耗策略、配网流程）→ 更新 `06-ESP32硬件模块.md`
- 修改了部署方式（Docker 配置、systemd 服务、定时任务）→ 更新 `08-配置与部署.md`
- 新增了项目模块或重大架构变更 → 更新 `02-系统架构.md` 和 `01-项目概览.md`
- 新增或修改了依赖项（requirements.txt、Arduino 库）→ 更新 `01-项目概览.md`
- 修改了前端页面结构或交互逻辑 → 更新 `05-Web服务器与前端.md`
- 新增了常见问题或调试技巧 → 更新 `09-开发指南.md`

## 更新原则

- 只更新受影响的文档，不需要全部重写
- 保持文档格式一致（参考现有文档的标题层级和表格风格）
- 如果变更较大，在修改完成后主动告知用户知识库已同步更新
- 新增内容应插入到文档中逻辑上最合适的位置，而非简单追加到末尾
- 删除功能时，同步删除知识库中对应的描述
